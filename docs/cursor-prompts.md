# Промпты для Cursor (Agent mode)

Правила проекта лежат в `AGENTS.md`, Cursor подхватывает его автоматически. Работаем spec-first: сначала спецификация, потом код.

---

## 0. Погружение в проект

```
Изучи репозиторий: README, AGENTS.md, src/, scripts/build-workflow.mjs, tests/.
Опиши своими словами поток данных от сообщения в Telegram до строки в таблице
и перечисли, какие граничные случаи уже обработаны. Код пока не меняй.
```

## 1. Eval промпта на размеченных примерах

```
Задача: регрессионная проверка качества извлечения перед изменением промпта или модели.

Сначала напиши спецификацию в docs/specs/eval.md и дождись моего ок:
- для каждого samples/*.txt создать эталон samples/expected/<имя>.json (заполню/проверю сам);
- scripts/eval.mjs вызывает тот же LLM-запрос, что и workflow (используй buildLlmRequest
  из src/build-request.js, промпт и схему из файлов), ключ из env OPENAI_API_KEY;
- сравнение по полям: точное для enum/чисел/дат, нормализованное для телефона/email,
  для summary - не сравнивать;
- вывод: таблица поле × пример и общий % совпадений; exit code 1, если ниже порога из аргумента.

После ок - реализуй, добавь npm-скрипт "eval" и раздел в README.
```

## 2. Дедупликация повторных заявок

```
Задача: если от того же телефона или email уже была заявка за последние 24 часа,
не создавать новую строку, а отметить повтор.

Сначала спецификация в docs/specs/dedup.md: где хранить историю (Google Sheets lookup
vs. отдельная таблица/Redis), что считать дублем, что отвечаем клиенту и менеджеру,
граничные случаи (разные форматы одного телефона, только email, спам).
Дождись моего ок. Потом: логика сравнения - чистой функцией в src/ с тестами,
изменения workflow - только через scripts/build-workflow.mjs.
```

## 3. Отправка в amoCRM вместо таблицы

```
Задача: добавить опциональную отправку заявки в amoCRM (сделка + контакт) через API.
Включается переменной CRM_TARGET=amocrm при сборке workflow, по умолчанию остаётся Google Sheets.

Сначала спецификация: маппинг наших полей на поля amoCRM, авторизация (долгосрочный токен),
обработка ошибок и ретраи, что делать, если контакт уже существует.
После ок - реализация: маппинг чистой функцией в src/ с тестами, HTTP-ноды в build-workflow.mjs.
```
