# Правила проекта для AI-агентов

Проект: Telegram-бот разбора заявок на n8n. Логика - в `src/`, workflow n8n генерируется скриптом.

## Архитектура
- `src/*.js` - чистые функции без зависимостей и без `require`: они встраиваются в Code-ноды n8n. `module.exports` всегда последний в файле.
- `AGENTS.md` - правила для AI-агентов (Cursor, Codex, Copilot и др.); `CLAUDE.md` только импортирует его для Claude Code.
- `prompts/` и `schema/` - промпт и JSON Schema для structured output. Схема строгая (`strict: true`): все поля в `required`, `additionalProperties: false`, необязательные значения - через `["type", "null"]`.
- `scripts/build-workflow.mjs` - единственный источник workflow. `workflow/*.json` руками не редактировать.
- В n8n данные между нодами передаются через `$json`. Ссылки `$('Node').item` использовать только внутри Code-нод.

## Правила работы
- Перед изменением поведения - короткая спецификация: что меняется, граничные случаи, как проверить.
- Любая новая логика - с тестами в `tests/` (`node:test`, без внешних библиотек).
- LLM не нормализует данные: форматы телефонов, дат, enum приводятся в коде.
- Текст клиента в промпте всегда внутри маркеров `<<< >>>`.
- После изменений: `npm run check`. Если менялась схема - обновить `SHEET_COLUMNS` и `samples/sheet-header.csv`.
- Секреты только в `.env` и credentials n8n, никогда в коде и workflow.
